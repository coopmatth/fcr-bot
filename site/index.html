Honest reading. 7 of 30 cells finished positive, and every variant still lost money summed across the five symbols — no adjustment turned the First Candle Rule into a broadly profitable system. The one consistent bright spot is gold (MGC): positive in 5 of its 6 cells, including the untouched baseline (+$584.00, +2.00R), the single best cell in the matrix. Partials (V3) reliably softened losses — higher win rates, shallower drawdowns — without creating an edge. Min-FVG (V1) backfired on MNQ (-$1,751.50): rejecting a setup does not end the day, it just hands the day to a later, worse setup. SPY and MNQ — the video's own market — lost under every variant.

Small-sample warning. Each cell holds only ~8–23 trades over ~60 days (roughly 13 in a typical run). At that size a few trades' difference flips almost any cell's sign — gold's entire baseline profit is about one extra winning trade — and picking the best of 30 cells is itself a form of overfitting: with 30 tries, chance alone manufactures a few good-looking cells. Nothing here is a validated edge; the gold column is a hypothesis for a longer test, not a result.

Caveats — read before trusting any number here

  • 5-minute bars for the 60-day run. Free Yahoo data only goes back ~7 days at 1-minute resolution, so the 60-day test runs the pattern on 5-minute bars (first 5-min bar = the first candle; FVG/retest/engulfing all on 5-min bars). The true strategy runs on 1-minute bars — the 7-day 1-minute run above is the real configuration on a tiny sample.
  • No slippage, spread, or commissions are modeled. Entries fill exactly at the engulfing bar's close; exits exactly at stop/target. Real MNQ fills would be worse by a few ticks per trade, and Tradovate micro commissions (~$0.39/side + exchange/clearing/NFA fees on the free plan) are not deducted.
  • Continuous-contract data. Yahoo's MNQ=F is an unadjusted front-month splice — quarterly rolls appear as price jumps. The strategy only uses intraday levels, but the data is still not exchange-grade.
  • The simulator never stops. Equity tracking is bookkeeping only: no margin checks, no halt at zero balance. One run (QQQ) ends below zero, which a live account could never do.
  • Sample size. One trade per day means even 60 days is only a handful of trades. These results describe how the rules behaved, not what they will earn.
  • Paper only. Nothing here places real orders. Live trading stays disabled by a hard-coded kill switch.
  • Tradovate API ≠ market data. The $25/mo API Access add-on covers orders and account data only — real-time market data through the API is a separate CME-licensed arrangement (demo uses simulated data). A live version needs its data feed sorted separately.
