Honest reading. 7 of 30 cells finished positive, and every variant still lost money summed across the five symbols — no adjustment turned the First Candle Rule into a broadly profitable system. The one consistent bright spot is gold (MGC): positive in 5 of its 6 cells, including the untouched baseline (+$584.00, +2.00R), the single best cell in the matrix. Partials (V3) reliably softened losses — higher win rates, shallower drawdowns — without creating an edge. Min-FVG (V1) backfired on MNQ (-$1,751.50): rejecting a setup does not end the day, it just hands the day to a later, worse setup. SPY and MNQ — the video's own market — lost under every variant.

Small-sample warning. Each cell holds only ~8–23 trades over ~60 days (roughly 13 in a typical run). At that size a few trades' difference flips almost any cell's sign — gold's entire baseline profit is about one extra winning trade — and picking the best of 30 cells is itself a form of overfitting: with 30 tries, chance alone manufactures a few good-looking cells. Nothing here is a validated edge; the gold column is a hypothesis for a longer test, not a result.

Gold bot — built (demo only, not deployed)

gold_bot.py runs the winning V0 baseline on MGC through the existing Tradovate DEMO layer: resolves the front-month contract each morning, feeds 1-minute bars to the same engine the backtester uses, places the entry as a market order with the engine's stop/target attached as an OSO bracket the moment a setup confirms, and liquidates anything still open at 15:55 ET. One trade per day. The config (config_gold.yaml) is frozen — the runner refuses to start if the symbol, sizing, or variant flags drift from the validated spec, if the kill switch is not in its off position, or if the client is not on the demo host.

Honest framing — read this before the table. The intraday window is 120 CALENDAR days (2026-06-22 → 2026-10-20), which is only 87 regular sessions for the futures and 84 for SPY (its data ends 2026-10-19) — roughly 84 trading days, not 120. Friction model. Gross numbers model no costs at all. It is an estimate, not a fill report, and it matters: several gross-green cells (e.g. previous-day sweep and VWAP reversion on MNQ) flip red after friction, which is why the ranking uses the after-friction column. As everywhere on this dashboard, the simulator never halts for balance or margin — several runs' paper equity goes deeply negative, which a real $500 account could never do; read those as strategy behavior under the house spec, not survivable account histories.

⚠ SPY data-integrity finding

The SPY 1-minute feed is not reproducible. Two separate downloads of the same SPY history from Databento's DBEQ.BASIC dataset disagree with each other: across the 84 overlapping days they share, 10,234 of 37,015 bars (about a third) differ in price or volume, and a third download disagrees with both. There is no single 'true' SPY tape in this data — each download is its own sample of a sampled feed. The futures data (GLBX.MDP3) does NOT have this problem: the gold file used here is bit-for-bit the lab's file and reproduces results to the cent.

How to read a MES result

MES and SPY are the same index, but ES futures trade nearly around the clock, so the 9:30 ET 'open' for MES is a continuation of overnight trading rather than SPY's auction open — a strategy keyed to the cash open can legitimately behave differently on the two, so a MES failure weakens but does not by itself falsify the SPY result, and a MES pass is strong feed-independent confirmation.

Databento flagged the whole GLBX.MDP3 dataset for degraded quality on 2025-09-17, 2025-09-24 and 2025-11-28 (the same flags noted on the gold file); the ES file retains those days in full (bars in file: 2025-09-17: 1377, 2025-09-24: 1379, 2025-11-28: 285) — nothing dropped.

Caveats — read before trusting any number here

  • 5-minute bars for the 60-day run. Free Yahoo data only goes back ~7 days at 1-minute resolution, so the 60-day test runs the pattern on 5-minute bars (first 5-min bar = the first candle; FVG/retest/engulfing all on 5-min bars). The true strategy runs on 1-minute bars — the 7-day 1-minute run above is the real configuration on a tiny sample.
  • No slippage, spread, or commissions are modeled. Entries fill exactly at the engulfing bar's close; exits exactly at stop/target. Real MNQ fills would be worse by a few ticks per trade, and Tradovate micro commissions (~$0.39/side + exchange/clearing/NFA fees on the free plan) are not deducted.
  • Continuous-contract data. Yahoo's MNQ=F is an unadjusted front-month splice — quarterly rolls appear as price jumps. The strategy only uses intraday levels, but the data is still not exchange-grade.
  • The simulator never stops. Equity tracking is bookkeeping only: no margin checks, no halt at zero balance. One run (QQQ) ends below zero, which a live account could never do.
  • Sample size. One trade per day means even 60 days is only a handful of trades. These results describe how the rules behaved, not what they will earn.
  • Paper only. Nothing here places real orders. Live trading stays disabled by a hard-coded kill switch.
  • Tradovate API ≠ market data. The $25/mo API Access add-on covers orders and account data only — real-time market data through the API is a separate CME-licensed arrangement (demo uses simulated data). A live version needs its data feed sorted separately.
